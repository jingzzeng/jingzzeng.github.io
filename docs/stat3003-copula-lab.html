Copula 模型

STAT3003 · Lecture 1.2

← 返回 STAT3003
依赖结构 + 边际分布 = 联合分布

先生成 (U, V) ∼ C，再令 X = F₁⁻¹(U)、Y = F₂⁻¹(V)。改变边际分布，观察同一组点如何变形。

设置模型

0.50

设置自动生效；只改边际时保留 (U, V)。每次“重新抽样”都会自动使用新的随机种子。

如何观察？

固定 Copula，只改变一个边际：秩相关保持不变，但 Pearson 相关系数可能变化。Gaussian 的 ρ 是潜在正态变量的相关系数，一般不等于变换后 X、Y 的相关系数。

比较 Gaussian、Clayton 和 Gumbel：观察左下角或右上角点的聚集。Student t Copula 即使 ρ = 0 也通常不独立。Copula 自由度与 t 边际的自由度是不同的参数。
